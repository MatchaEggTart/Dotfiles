# 个人画像

这个文件记录**对这个人有效的教法**，跨所有工作区共用。每开一课先读它。

## 规则（给 agent）

- **没有锚点不写。** 每条必须指向一个发生过的事件：课、learning record、用户原话。
  你自己的判断不算证据。
- **攒够三条同类证据再升级。** 不足就先记进 `learning-records/`，别急着写这里。
- **不删，只作废。** 不成立了就标 `superseded by LR-NNNN`，保留原文。
- **这里不是日记。** 不要记录「第几课上了什么」，那也是 learning record 的事。

条目格式：

```md
**<一句话概括这条习惯>**
<为什么有效 / 怎么用它，一到两句。>
证据：<锚点>
状态：active
```

## 通用

系统补数学会显著拖慢进度；只在卡住时补，且只补当前阶段真正用得到的那几块。
证据：`ai-notes/docs/ai-roadmap.md` §2「数学怎么补」明确写「不做系统数学课……卡住才补」
状态：active

**术语必须中英对照，必要时带法语**
概念没有丢，只是换了语言；术语桥能把「法语概念」接回「英文术语」。
证据：`ai-notes/docs/ai-roadmap.md` 的「中 / 英 / 法 术语桥」
状态：active

**先给可运行的最小数值例子，再给规则**
规则先讲、例子后补，会变成「读着懂、写不出」；反过来先跑通一个最小例子，规则才有落点。
