# RESOURCES.md 格式

`RESOURCES.md` 是这个主题的可信来源清单。课里的知识应该从这里取，**不要从参数化记忆里取**。
智慧来自这里列出的社群。

## 结构

```md
# {主题} 资源

## 知识

- [书：《XX》作者](链接)
  一句话：讲什么。什么时候该翻它。
- [文章：「XX」作者](链接)
  一句话：讲什么。什么时候该翻它。

## 智慧（社群）

- [r/xxx](链接)
  一句话：什么样的社群。适合用来干什么。
- 线下：{某处的某课}
  适合用来干什么。

## 缺口

- {mission 需要、但目前没有好来源的方向}
```

## 规则

- **只要高信任度。** 优先一手来源、公认专家、同行评议、管理严格的社群。
  披着教育外衣的营销材料，不要收。
- **每条都要注释。** 三个月后一个裸链接等于没有。一行说明它覆盖什么、什么时候去翻。
- **按知识 / 智慧分组。** 一个资源只出现在一组里也可以。
- **显式记录缺口。** mission 需要但找不到好来源时，写进 `## 缺口`。这驱动后续的搜索。
- **狠心修剪。** 被证明是错的、浅的、偏题的资源，删掉而不是埋起来。五个锋利的来源胜过
  三十个平庸的。
- **记下用户的社群偏好。** 用户说过不想加入社群，就写在这里，以后别再反复提议。
