# Learning Record 格式

放在 `./learning-records/`，顺序编号：`0001-slug.md`、`0002-slug.md`。目录懒创建。

它们是教学版的 ADR：记录非显然的收获、关键洞察、以及用户已声明的既有知识。
**用途是算最近发展区** —— 决定下一课从哪教。

## 模板

```md
# {简短标题：学到了什么 / 已经会什么}

一到三句：学到了什么（或确认了什么既有能力），以及它为什么改变下一课的选择。

证据：{课 / 用户实跑通过的东西 / 用户原话}
```

模板就这么点。一条 learning record 可以只有一个自然段。价值在于记下「这现在是已知的、
所以下一课该怎么变」，不在于把格子填满。

## 可选段落

只在真的有用时加。多数记录不需要。

- **状态**（`active | superseded by LR-NNNN`）：当早先的理解后来被推翻并替换时。
- **影响**：这条解锁了什么、排除了什么。非显然的时候才值得写。

## 编号

扫一遍 `./learning-records/`，取最大号加一。

## 什么时候写

满足任一条就写：

1. **用户展示了真实的非平凡理解** —— 不只是接触过，是有证据说明他能正确使用这个概念。
   这抬高了下一课的地板。
2. **用户披露了既有知识** ——「这个我已经会了」。记下来，也要记宣称的**深度**，
   否则以后的课会重复教。
3. **一个误解被纠正了** —— 用户原以为 A，现在明白为什么是 B。这类价值最高，
   它能预测相关话题上后面的绊脚石。
4. **mission 因为学习而移动了** —— 用户发现自己真正在意的是别的东西。交叉链接到
   `MISSION.md` 并更新它。

## 什么不算

- **只是「覆盖过」的材料。** 覆盖不等于学会。等证据。
- **已经压缩进 `GLOSSARY.md` 的术语定义。** 不要重复。
- **逐次会话的活动日志。** learning record 不是日记，是决策级的洞察。
