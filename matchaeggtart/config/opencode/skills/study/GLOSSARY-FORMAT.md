# GLOSSARY.md 格式

`GLOSSARY.md` 是这个教学工作区的规范语言。所有课、练习、learning record 都要遵守它的术语。
**建设术语表本身就是学习** —— 把一个概念压成一句紧的定义，是理解的证据。

## 结构

```md
# {主题} 术语表

一到两句，说明这份表覆盖什么。

## 术语

**增肌**：
反复训练下由机械张力与代谢压力驱动的肌肉生长。
_避免_：涨块、变壮

**渐进超负荷**：
随时间系统地提高对肌肉的要求，手段是负重、容量或强度。
_避免_：练得更狠、升级
```

## 规则

- **用户懂了才收。** 术语表是压缩后的知识的记录，不是拿来读的词典。刚介绍过的概念先等等，
  等他能正确使用了再收进来。
- **要有主见。** 一个概念有好几种叫法时，挑最好的那个，其余列进 `_避免_`。语言就是这么压缩的。
- **定义要紧。** 一到两句。定义它**是什么**，不是它做什么、怎么做。
- **在定义里用表内的词。** 一旦某个词进了表，所有地方都优先用它，包括别的定义里。
  这是让复杂概念以后更好抓的关键。
- **自然成簇时分组。** 比如 `## 数学`、`## 训练`。词很杂时一个平铺列表就够了。
- **显式标注歧义。** 某个词在领域里用法松散，就写下这里的约定：
  「在本工作区，『组』永远指正式组，热身单独记。」
- **随理解加深而修订。** 第一周写的定义到第六周可能就是错的。就地更新，不要留过期条目。
- **别记可检索的东西。** 搜索引擎或 AI 能立刻给出的定义，不属于这里；这里记的是**你自己的**
  压缩结果。
